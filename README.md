# Сайт для Женечки

Обычный сайт без сборки: четыре файла.

| Файл | Что внутри |
|---|---|
| `index.html` | каркас страницы |
| `style.css` | цвета, шрифты и все анимации |
| `script.js` | настройки сверху, логика дней и анимаций |
| `texts.js` | все 30 дней текстов |

## Открыть в VS Code
1. Поставь расширение **Live Server** (автор Ritwick Dey).
2. Правый клик по `index.html` → **Open with Live Server**.
3. Любой день можно посмотреть так: `index.html?day=7` (число от 1 до 30).

## Как работают дни
В `script.js` вверху стоит `START_DATE`. В эту дату показывается день 1,
на следующий день 2 и так далее. После 30-го всё идёт по кругу.
Смени дату на ту, с которой хочешь начать.

## Тексты
Правь `texts.js`. Меняй только то, что внутри кавычек. Пустая строка в тексте это `\n\n`.

## Анимации
- Фон: каждый день свой набор (сердечки, лепестки, искорки, бабочки). Список в `script.js` (`PARTICLES`).
- Каждая кнопка появляется по-своему (кадры `letterIn`, `blossom`, `jackbox`, `squeeze` в `style.css`).
- Секретное письмо печатается по буквам, клик по нему показывает всё сразу. Скорость: `TYPE_SPEED`.
- Если в системе включено «уменьшить движение», все анимации отключаются сами.

## GitHub Pages
1. На github.com создай репозиторий (например `zhenya`), публичный.
2. В папке сайта:
   ```
   git init
   git add .
   git commit -m "site"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_НИК/zhenya.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch → main / (root) → Save**.
4. Через минуту сайт будет по адресу `https://ТВОЙ_НИК.github.io/zhenya/`.
